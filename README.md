# GTA SA Cheat Keyboard (Android)

An Android keyboard with one-tap buttons for GTA San Andreas cheat codes.
Each code is sent as real A–Z key presses. The app source is in `gta-cheat-keyboard/`.

GitHub Actions (`.github/workflows/gta-cheat-keyboard.yml`) builds the APK on every push and
publishes it to the `gta-cheat-keyboard-latest` release:
https://github.com/sheshnath29/Price-tracker/releases/download/gta-cheat-keyboard-latest/gta-cheat-keyboard.apk
